# Consigna de la práctica 2

La fuente es el [enunciado original](../../Práctica_2.md), conservado en la raíz. La fecha de entrega que aparece allí pertenece a la consigna original y no se modifica con la actualización técnica.

## Documentación requerida

1. Requerimientos funcionales y no funcionales.
2. Análisis y diseño: arquitectura, circuito de cada objeto, clases, secuencia y protocolo.
3. Desarrollo e implementación con enlaces al código.
4. Pruebas y validaciones.
5. Resultados.
6. Conclusiones.
7. Recomendaciones.
8. Anexos.

El proyecto se documenta en Markdown, con código y evidencias en el repositorio. La demo debe mostrar la comunicación mediante el servidor; probar sensor y LEDs por separado es una preparación, no la validación integrada.
