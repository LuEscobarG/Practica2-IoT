## Trabajo restante

- Configurar la red real y cargar el firmware correspondiente a cada placa.
- Ejecutar integración local y recuperación frente a cortes.
- Medir exactitud, frecuencia de adquisición, respuesta y estabilidad.
- Verificar el recorrido entre redes distintas si se demostrará funcionamiento por Internet.
- Adjuntar evidencias y actualizar resultados, conclusiones y recomendaciones del informe.
- Ensayar demo y defensa con aportes de cada integrante verificables en Git.

Una tarea física se cierra con un registro y evidencia, no solo con el procedimiento escrito.
